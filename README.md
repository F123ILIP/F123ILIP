## Project ideas (next “wow” items)
Here are ideas that recruiters in ML/Data usually react well to (each can become a polished case study):

1) **End-to-end Time Series Forecasting (Azure + Power BI)**  
   - Forecast demand/volume (synthetic or public data)  
   - Pipeline: ingestion → cleaning → model → evaluation → dashboard with forecast & uncertainty  
   - Bonus: monitoring drift + retraining schedule

2) **Geospatial analytics (fits Geoinformatics MSc)**  
   - “Where to open a new point of service?” using OSM + demographics + travel time  
   - Deliverable: interactive map + scoring model + report (assumptions + limitations)

3) **ML model evaluation “playbook” repo**  
   - A clean template: cross-validation, leakage checks, baseline comparisons, metrics table  
   - Shows maturity: you understand how models fail, not only how to train them

4) **A/B test analysis + dashboard**  
   - Simulate an experiment or use public product data  
   - Write a short “decision memo”: what changed, confidence, recommendation

5) **Data quality checks + automated reporting**  
   - Great for analytics roles: tests for missing values, schema drift, outliers  
   - Output: daily HTML report + simple alerting (even without full MLOps)
